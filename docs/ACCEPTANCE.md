# Physical iPhone acceptance checklist

Not yet executed. Use the unsigned **device** IPA after a successful Actions run.

- Install via SideStore and launch; verify five tabs and light/dark appearance.
- Search for “Pride and Prejudice”; choose Project Gutenberg #1342.
- Open source rights; download its EPUB with images; verify real progress and completion.
- Read, turn pages, use chapter navigation and open an internal link.
- Change font family, size, line spacing, margins, theme and continuous scrolling.
- Select a passage, highlight it, add a note, create a bookmark and search for text.
- Close the reader, terminate the app, enable airplane mode and relaunch.
- Open Library → downloaded book. Verify position, highlight, note and bookmark persistence.
- Navigate to the saved bookmark and delete an annotation.
- Check activity time; background the app for a minute and confirm excluded time.
- Read selected text aloud; verify pause, resume and stop.
- Delete the download, verify freed storage and inability to open its removed file.
- Disable airplane mode, retry download, then remove the library entry.
- Test an openly licensed Archive PDF: search, page jump, pinch zoom and offline resume.
- Test download cancellation, app termination during download, low storage, disconnected
  networking, failed covers, VoiceOver, largest Dynamic Type and Reduce Motion.

Record device model, iOS version, commit SHA and SideStore version with results.
